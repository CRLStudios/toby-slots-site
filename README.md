# Toby Slots site

The public pages for the Toby Slots iPhone game, served by GitHub Pages:

- Support: https://crlstudios.github.io/toby-slots-site/support/
- Privacy policy: https://crlstudios.github.io/toby-slots-site/privacy/

The game links to the privacy policy from its Settings screen, and both addresses are entered in App Store Connect, so do not move or rename them.
